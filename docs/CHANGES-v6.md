# Changes in v6.0

This is a source-integrated successor to v5, not a visual mockup or a standalone diagnostics report.

## Added

Authoritative server world; multi-view synchronization; atomic in-progress checkpoints; explicit bounded detached operation; a production no-CDN isometric renderer; actual land-outline data and optional real elevation input; bounded generated local terrain and navigation; localized reservable material nodes; carry mass; seasonal/ecological updates; household stores; funded contracts/escrow and consenting barter; four-stage room construction and wall/door navigation; 42 object definitions; 38 process families; appearance/trait editing; family and genealogy workspace; culture/projects/tutoring/written artifacts; finite water/power uses; contextual conversations; Jev-selected arithmetic and measured numerical predictor paths; new domain selection for large action menus.

## Retained and adapted

Native TypeSafe by default; independent recipient Jev choices; optional OpenRouter decisions; optional grounded cloud/agy proposals; personal and witness memories; concurrent activities; biological time scales; births/aging/consent; budget/error pauses; full raw ledger; migration from prior checkpoints and the supplied turn-74 recovery.

## Corrected during integration

Server callbacks settle cancellation before checkpoint/close; the browser does not become a second decision host; recovered scenery rebuilds from server identity; impossible heat/power prerequisites fail before material consumption; waterwheel output requires a local water source; predicted result is not accepted as a real outcome; computer programs need a Jev-selected instruction; child practical knowledge is not inherited; invalid editor traits/terrain inputs leave state unchanged.

## Transparency

Graphics are stylized. The real land outline and optional terrain heights are not a real full-Earth resource database. Advanced scenarios are explicitly seeded, not simulated historical achievements. Physics/material processes are simplified and finite. No authenticated model call and no WebGL visual validation were possible in the build environment. The actual shipped isometric scene was tested and inspected on desktop/mobile.
