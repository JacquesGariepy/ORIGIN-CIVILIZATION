# Consolidated changes since v4.2

This is a runtime/gameplay change, not only a TypeSafe connector change.

## Replaced

The old global actor cursor/session loop no longer runs the live UI. New activity objects overlap in time, while requests are concurrent and bounded. The local server's one-request-at-a-time rejection was replaced by an explicit concurrency limit. Old code is retained for reference and save migration.

## Added

- Ten needs, ordinary play/run/sleep/washing/rest, traits, outward expressions.
- Own directed social bonds, adulthood/kinship gates, family links, growth, pregnancy and children with empty learned memory.
- Two household stores, eight object definitions, reservations, condition/cleanliness, build proposals and material consumption.
- Non-forced invitations: arrive, ask recipient, then accept/refuse. Receiver activity is validated before interrupting it.
- Real shared resource effects; remaining-work options after interruption.
- Independent evidence inference after a physical action, not rollback of the physical past.
- Technology recipes extended through a numeric VM and a small fitted predictor with recorded training samples.
- Six English UI pages, concurrent activity counters, person tabs, mobile panels, camera/cutaway controls.
- v5 snapshots, active-task restore and original turn-74 migration.
- New engine, concurrent HTTP and DOM fixture tests; native provider contract regressions retained.

## Preserved

Native TypeSafe default, explicit OpenRouter alternative, optional cloud or agy proposal path, key redaction, visible request budgets, no local behavior fallback, original procedural 3D assets and prior recovery data.

## Not represented as completed

Global Earth resources, photorealistic humans, fluent emergent language, arbitrary room/wall construction, a modern career/economy system, historically validated industrial processes, open-ended invention, general AI and subjective consciousness. See the implementation-status table, not a feature claim inferred from the project ambition.
