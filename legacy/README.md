# Legacy reference

The v4.2 HTML and source are retained to document the starting point and support debugging/migration. They are not the v5 entry point. Launch the root ORIGIN.html using the root start scripts.

The root source/session.js, source/ui.js and source/shell.html are old regression references; build.cjs uses living-session.js, living-ui.js and living-shell.html instead.
